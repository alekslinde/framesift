How layers are named

Each layer gets a name describing what it is, worked out in order:

  • Text layers use their own text — “Sign in” becomes _sign-in.
  • Image fills become _image.
  • Recognised names are kept as a role — a layer called “Nav bar” becomes _nav.
  • Groups and frames are named from what they contain — an image with text becomes _card.
  • Anything else falls back to its type — a rectangle becomes _bg, a vector _icon.

Goes three levels deep. Components, instances and locked layers are never touched. The _ prefix marks a generated name, so running this again leaves them as they are.
